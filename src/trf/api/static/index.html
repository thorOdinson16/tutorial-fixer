✓Tutorial Rot Fixer

Make an old tutorial run again.

Give it a Python tutorial and it returns a version whose code runs on current libraries. Every block is executed in a sandbox, and every change links to the release note behind it.

Blog posts and documentation pages both work. Old versioned docs addresses (for example /pandas-docs/version/1.5.3/) tell the tool which library version the page was written for.

Settings

Each round reads the error, looks up the call that broke, and tries again. 0 turns it off.

Add a tutorial to see a time and cost estimate.
