# tutorial-fixer

Tutorial Rot Fixer: a LangGraph multi-agent system that updates outdated Python tutorials
(Pydantic v1 → v2, pandas 1.x → 2.x) and verifies the result by running it in a Docker sandbox.

The project lives in [`tutorial_rot_fixer/`](tutorial_rot_fixer/):

- [README](tutorial_rot_fixer/README.md): what it does, architecture, status and results
- [SETUP](tutorial_rot_fixer/SETUP.md): prerequisites, install, Docker, corpus, LLM configuration
